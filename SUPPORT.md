# Support

Menubench is free and open-source software maintained on a best-effort basis.

Before opening a report, check the [troubleshooting guide](docs/TROUBLESHOOTING.md), confirm you are running the latest release, and verify the relevant macOS permission in System Settings.

- [Report a bug or request a feature](https://github.com/augrclk/menubench/issues/new/choose)
- [Read the privacy notes](docs/PRIVACY.md)
- [Review macOS permissions](docs/PERMISSIONS.md)
- [Report a vulnerability privately](https://github.com/augrclk/menubench/security/advisories/new)

Useful bug reports include the Menubench version, macOS version, Mac model, reproducible steps and a screenshot with private data removed.
